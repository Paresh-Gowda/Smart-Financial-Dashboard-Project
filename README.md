# 💰 Smart Finance Dashboard

Smart Finance Dashboard is a simple yet effective web application that helps individuals take control of their personal finances.
By providing an organized way to record salary, expenses, and savings, it gives users a clear overview of their financial status in one place.
The goal of the project is to make money management easier, smarter, and more transparent for everyday users.

The project is powered by Flask on the backend with SQLite as the database to securely store financial data. 
The frontend uses HTML, CSS, and JavaScript for a smooth interface, while Chart.js is integrated to create engaging data visualizations such as bar charts for income and expenses. 
Together, these technologies provide both simplicity and interactivity, ensuring users can track and understand their finances effectively.

Beyond basic tracking, the dashboard is designed to serve as a foundation for future features like advanced savings insights, investment analysis, and personalized recommendations. 
By combining data management with clean visuals, Smart Finance Dashboard shows how technology can simplify financial decision-making and help users build better money habits.
